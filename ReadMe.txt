FolderCopyUtility

To run FolderCopyUtility from terminal (fast)

- this will instantly run the program

To run FolderCopyUtility using exe
- navigate to this folder "E:\GIT\Python\FolderCopyUtility\dist\FolderCopyUtility"
- double click FolderCopyUtility.exe
- right click to pin to task bar if you like
